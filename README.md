# Dr. Emre Yavuz

PhD computational neuroscientist (UCL, spatial navigation) who ships. I build agentic AI and LLM apps for health and behaviour, mostly in TypeScript, Python and R.

🌐 [emreyavuz.vercel.app](https://emreyavuz.vercel.app)

## Products

| | What it does | |
|---|---|---|
| 🏆 [**BoneBot**](https://github.com/eyavuz21/bonebot) | Hormone-aware bone-health screening for postmenopausal women. Winner, Hack-Nation Global AI Hackathon | [live](https://bonebot.vercel.app) |
| 🥈 [**Heard**](https://github.com/eyavuz21/heard) | One-tap speech relay for dysarthria. 2nd place, Consumer Health Hackathon | [live](https://heard-iota.vercel.app/live) |
| 🎻 [**Stuckato**](https://github.com/eyavuz21/stuckato) | Couch to 5K for practising an instrument, with the teacher in the loop | [live](https://stuckato.app) |
| 🧭 [**Bearings**](https://github.com/eyavuz21/bearings) | Smartphone-only life-space recovery after surgery. Crick Innovation Challenge | [live](https://bearings-olive.vercel.app) |
| 🛍️ [**Noticed**](https://github.com/eyavuz21/noticed) | Client book for independent retail, suggestions from the shop's own stock | [live](https://noticedapp.vercel.app) |
| 🅿️ [**ParkAndSave**](https://github.com/eyavuz21/park-and-save) | Agentic trip planner where the agent builds its own UI (CopilotKit, AG-UI, A2UI) | [live](https://parkandsave-agent.vercel.app) |
| 🌿 [**Serenetripity**](https://github.com/eyavuz21/serenetripity) | Mood-led journey planning through the city | [live](https://serenetripity.vercel.app) |
| 🚶 [**Wander**](https://github.com/eyavuz21/wander) | Walking routes that optimise for the person: calm streets, discovery, movement | [live](https://cursor-hackathon-2026-07-09.vercel.app) |
| 🛒 [**SpatialCart**](https://github.com/eyavuz21/spatial-cart) | Grocery shopping as a routing problem | [live](https://eyavuz21.github.io/spatial-cart/) |
| 🎧 [**Sounday**](https://github.com/eyavuz21/sounday) | Turns your calendar into a personalised soundtrack | [live](https://sounday-piqy.onrender.com) |
